# 🏦 Bank Simulation Program

A simple **Bank Simulation Program** built with Python.
This project simulates basic banking operations such as user login, checking balance, depositing money, and withdrawing money.

## 📌 Project Description

The program starts with a login system that gives the user **3 attempts** to enter the correct username and password.

After successful login, the user can access a bank menu and choose between:

* Check Balance
* Deposit Money
* Withdraw Money
* Exit

The program also validates the entered amounts and prevents withdrawals when the balance is insufficient.

## ✨ Features

* 🔐 Username and password authentication
* 🔢 Maximum of 3 login attempts
* 💰 Check current balance
* ➕ Deposit money
* ➖ Withdraw money
* 🚫 Prevent invalid deposits and withdrawals
* 🔒 Lock the account after 3 failed login attempts
* 🚪 Exit the banking system
